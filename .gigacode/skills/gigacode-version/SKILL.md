# Получение версии GigaCode Desktop

## Назначение
Получение текущего номера версии GigaCode Desktop с официальной страницы версий GigaCode.

## Инструкции по выполнению
1. Отправьте GET-запрос к `https://gigacode.ru/jarvis/versions`.
2. Ответ представляет собой JSON-массив, содержащий версии для различных платформ.
3. Найдите первый элемент, поле `type` которого начинается с `DESKTOP`, и извлеките значение поля `version`.
4. Выведите пользователю текущий номер версии.

## Ожидаемый результат
Выведите в формате: `Текущая версия GigaCode Desktop: {version}`
